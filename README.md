# FeagueShow
A Visual Novel System running on Godot Engine 4.7, featuring (somewhat) simple character to text system, alongside advanced features.

## Page under construction, source release when ready.

# What is FeagueShow?
FeagueShow (formerly known as BinkNovelEngine) is a visual novel system built to offer easy access to the visual novel space, while supporting advanced features of the Godot Engine. You can expand on the features by writing your own code, or use the pre-built features within the system.

The system may need some familiarity with GDScript, but it's made to try and be as simple as I could make it.

This system was originally made for a visual novel game I'm working on, but I wanted to make it open source.

# Roadmap
FeagueShow is looking for a barebones release somewhere soon, featuring character sprites, simple talking amongst not so unique features.

The system will receive new updates on GitHub alongside it's development on the game it's being used for.
